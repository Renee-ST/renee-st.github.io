# Renee academic homepage setup

This package contains only the files that need to be replaced or added on top of the original `luost26/academic-homepage` template.

1. Start from the full `luost26/academic-homepage` template.
2. Copy these files into the same paths in your `renee-st.github.io` repository, overwriting existing files when prompted.
3. Keep the template's other folders and files (`_layouts`, remaining `_includes`, `assets`, `Gemfile`, etc.).
4. GitHub Pages should publish from the `main` branch and repository root.
5. The portrait is loaded directly from `https://github.com/Renee-ST.png`, so changing your GitHub avatar will update the homepage avatar automatically.
6. Later, add Google Scholar or CV by uncommenting the corresponding fields in `_data/profile.yml`.
